    Set your TMDB API key

    The app talks to TMDB directly from your browser. Your key stays on this device (localStorage) and is never sent anywhere else.

    1. Create a free account at themoviedb.org.
    2. Go to Settings → API and request a key (choose "Developer").
    3. Copy your API Read Access Token (v4) or your API Key (v3) and paste it below.
